# 使用指南

安装与接入从[README](../README.md)开始。枢模的日常入口是DSH原生会话，源码/安装目录与业务工作区分开，用户资料不写入软件包。

## 任务流程

| 步骤 | 你需要查看什么 |
|---|---|
| 提交题目 | 原题、全部所需附件、处理的小题和强制输出；缺项先讨论 |
| 方案讨论 | 假设、算法、单位、检验方法及独立M1检查对应的当前方案 |
| 确认方案 | 打开当前完整稿，明确通过或提出修改 |
| 求解与结果 | 最小案例、完整计算、带单位表格、代表图、误差和独立检验状态 |
| 确认结果 | 决定哪些当前结果可进入写作；限定误差接受单独记录 |
| 图文审阅 | 完整中文Markdown与全部候选图，标出暂列入文和备选图 |
| 正式导出 | 经批准内容的同源文档、完整页检查、独立W2及实际成品 |

在当前审阅文件展示后，原会话明确回复“通过”或提出具体修改意见。同一写作运行/汇编与版本的正文和配图可一次确认，后台原子保存两类范围。新版必须重新展示；旧回复、模型代述和工具权限弹窗不能批准新内容。

## 论文与图表

中文建模论文围绕问题分析、模型、求解、结果、检验和评价组织。全篇使用一个统一符号表，列出含义、单位及适用范围；同名异义先明确重命名或作用域映射。

默认三类候选图各至少3张、合计至少9张，正式入文至少8幅。图数是项目当前质量要求，题目或用户明确调整时记录依据。时间/几何题按实际科学问题提供代表时刻和必要实物细节，示意图本身不等于物理或碰撞检验。

所有候选与正式PDF核对完整页数、逐页生成预览并检查、保留哈希；实际读图、独立质检和用户确认各自执行。工具编译成功不能代替这些检查。

## 误差与修订

分别说明题目要求和项目自定精度。难以达到自定阈值时，应披露实际误差、单位、时空位置、影响及改进成本，再由用户决定。接受偏差保留原阈值FAIL，不等于其他检查或正文已通过。

修改模型、数值、图或正文时按影响生成新版本，不直接改已登记产物的字节。需要阅读副本时可复制文件，但副本不产生新批准。

## 继续与恢复

重开原会话后先读取原任务状态和回执，再继续同一任务。不同小题独立建立范围，跨题引用绑定明确版本。收到`outcome_unknown`先查询原请求，不换请求键重复求解。

若已收到响应但JSON结构或证据引用非法，按内容/证据问题处理，不套用未送达恢复。每个attempt最多一次独立复核，不能通过反复请求刷到PASS。原小题无待办但汇编仍待审时，应定位实际引用该题的当前汇编。

配置、宿主和错误处理分别见[用户配置](user-configuration.md)、[DSH说明](dsh-local-connection.md)和[排错指南](troubleshooting.md)。
