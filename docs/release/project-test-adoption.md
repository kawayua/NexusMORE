2026-11-11：按用户决定，11项上游业务测试的验证目标予以保留，与枢模实际接口及项目规则结合。已覆盖的自有测试直接沿用；有可核验授权且接口适用的上游代码可复用，但本批上游测试未取得覆盖全文的明确授权，因此不直接复制。固定Apache官方工具继续按原许可证使用，测试场景由本项目编写。

原测试方法与场景目录见[分类审查](upstream-tests-review-20261111.json)，本轮新增代码、依赖、运行结果与未实现能力见[适配回执](project-test-adoption-20261111.json)。本文件不把“场景已登记”写成“功能已接通”。

|---|---|

| 独立质检 | 沿用实际身份、上下文、版本失效和失败路由测试；文档关键字存在不能代替机制成立 |
