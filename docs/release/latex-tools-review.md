## 值得保留的目标

模板来源、适用版本与哈希记录；显式主入口、保留类文件和配套资源；代码/数据/图片副本与权威来源绑定；输入包含、重复标签、图表题注与正文引用、文献键、子问题覆盖及占位符检查；编译日志和实际工具身份；不启用shell escape；编译前后核对源码；产物与构建清单配对。这些目标与枢模可追溯流程相容，但源码检查、编译通过、实际PDF检查、独立W2和用户批准必须分别记录。

后端统一Python不意味着禁止TeX排版源码、编译器或原生Word渲染工具。它们是由Python编排的外部工具，不引入其他业务后端语言。当前项目已有Pandoc/Tectonic发现与同源导出，不因上游默认XeLaTeX就静默换编译器，或要求安装所有候选引擎。确需指定引擎、宏包或BibTeX/Biber后端时，按实际模板逐项适配与验证。

## 不能直接接入的地方

**发布门禁与全页检查不完整。** 上游 `build_paper` 的passed取决于源码是否改变及编译日志，未调用完整 `inspect_paper`，也没有模型/结果确认、正文/选图双确认或独立W2。源码占位符、全文质量与PDF审计是另一个命令，发布本身不能证明这些检查通过。指南最终只要求抽检；doctor只发现pdftoppm，没有全页渲染与预览哈希清单。枢模须复用全部候选图、LaTeX PDF和Word渲染PDF的全页检查，页数/预览/派发图像完整核对后再进入独立审查，不能跳过PDF仍给最终交付通过。

**模板与阈值不能覆盖本地政策。** 中文基线合并问题重述/分析、假设/符号，没有强制摘要后分页，无法独自实现当前章节与一个全局符号表。英文版不是默认中文建模体裁。上游15000字词、20页、5个公式、3张表是其质量目标，不是当前项目通用要求或已核验的当届官方规则；8图也不能代替三类候选图、每题覆盖和逻辑图计数。命令行理由字符串不等于明确用户确认，不允许据此降低本地阈值。官方页数限制必须记录实际来源及适用范围。

**自动校验有明确范围。** PDF检查只扫描页级字体及Type0子字体，不递归Form XObject字体，并将Type3和标准14字体直接视为嵌入；与当前项目检查口径不一致。文字/内容读取异常被转为空值，位图工具输出无法解析时也需区分“确实无位图”与“未完成审计”。正则能查部分包含、标签、引用和环境，不能验证文献真实性、公式等价、全局符号语义、实际版面或全部宏展开。采用时接现有PDF检查并保留警告/人工复核，不泛称安全或版面全通过。

**路径、覆写和失败留痕需重整。** 上游仅禁止写入推算的SKILL_ROOT，将LaTeX项目直接父目录当PROJECT_ROOT；不等于枢模实际数据目录授权，也未显式覆盖Windows junction。`--overwrite`、固定build路径及更新绑定清单不能覆盖历史通过产物。临时副本、`-no-shell-escape`、`latexmk -norc`和openin/openout限制可参考，但不等于完整操作系统隔离；宏、cls/sty及外部程序仍有执行边界。编译非零或超时时，可能在日志持久化前抛错并清除临时目录；须保留完整命令、输出和失败回执。PDF/清单在普通异常时回滚，不等于进程崩溃时成对原子提交。

**预警例外与Word转换不能冒充接通。** 任意正则加非空理由可以放过一批编译预警，应改为有具体范围、依据和实际审阅证据的例外，不能代替用户决定。指南引用的 `equations.py convert-latex` / `convert_latex` 不在当前固定Apache DOCX工具包及已注册接口中。枢模现有从已批准Markdown经Pandoc生成原生OMML的流程，不等于任意LaTeX源码无损转Word；通用转换、模板路由与适用引擎仍按后续任务实现和实测。
