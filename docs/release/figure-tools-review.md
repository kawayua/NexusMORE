## 必须保留的枢模规则

先有可核验数据及图表问题/论断，再建立面板证据链、绘制、自检、实际读图与修订。未验证结论先写待检验问题，不能从偏好的模板推定有利结论。每幅图绑定原始输入、合同版本、执行、结果revision、代码、参数和字节哈希，符号与单位服从全文全局表。

三类候选raw/process/result各至少3张、总至少9张，正式入文至少8幅，并按当前政策覆盖各题；PNG/PDF/SVG与灰度预览不是不同逻辑图。PNG至少300dpi，最终物理尺寸、字形、裁切、灰度和图意实际检查；外部3种图型、Nature栏宽或固定字号不自动成为新增硬约束。模型、结果、正文和选图的批准按原规则分别记录。

代码手生成真实结果与候选图，论文手组织论断、候选预览和选图讨论，P2/W2由未参与被审产物编写/修正的独立上下文只读审查。作者AI读图、自检或脚本PASS不能代替独立门禁，更不能代替用户选图。当前P2请求以文本/JSON证据为主，不能据此宣称已目视全部PNG；特定汇编W2路径支持真实页图审查，也不代表任意任务/供应商已具备通用读图能力。

候选图可在写作前生成PDF/SVG/PNG；**图文件导出与正式论文导出是不同操作**。正式论文仍须当前正文和最终选图分别明确通过，再同源排版与实际渲染/W2。只增未入文候选图时保留字节未变的正文批准，采用新图或改变题注/正文后重新确认受影响部分。几何/运动题应按题目提供代表时刻和真实尺寸，示意图不冒充碰撞或数值检验。

## 静态审查发现

**后端和范围有内部冲突。** 核心contract限定Python/MATLAB并排除R，stance仍写支持R，源码校验器实际只提供Python/R且R仅做括号/正则预检。入口说“不做示意图”，自身契约又列schematic-led版型。枢模按现有Python路线实施，MATLAB/R单独决定和验收；不要从这些文档推断支持。必要几何、实物或建模示意保留，标清其证据属性。

**数据与统计示例不能直接带入生产。** 配方含随机小鼠/噪声样本，教程收敛均值和标准差也由随机数生成，只能作demo。真实轨迹、n、p值、误差棒和区间必须来自实际计算及适用统计前提，确定性问题不编造不确定性。`profile_data.py:310`之后默认推断CSV/XLSX表头，可能漏掉无表头首行；相关性计算在182行整体dropna，却没有记录该矩阵实际保留样本数。需显式表头/工作表/首末行/行数，并留缺失值与筛选计数。

**导出函数不等于完整绘图服务。** `export_figure.py:91`之后直接改全局样式并savefig，没有调用读图/布局门禁、任务输出边界、不可变版本或图哈希校验。多格式逐个写入可能留下部分产物，tight裁边后实际物理尺寸需再量，灰度流程在142行还会重新写PNG。应使用受控任务目录和新版本，在三格式及QA完成后冻结，避免覆盖已确认图。

**检查存在跳过或仅提示的路径。** `check_figure.py`缺Pillow/pypdf时可跳过必要检查，PDF解析异常仅WARN，不加strict即使FAIL也返回0；SVG仅检查前50000字符。PDF字体逻辑未完整递归子资源，静态代码不能证明所有字体已验证。`layout_tools.py`可吞掉布局异常/警告后返回none；不能拿零退出码、未见FAIL或字段名“PASS”当完整验收。必要证据/依赖缺失应明确BLOCKED，WARN逐条核查并记录理由。

**实际读图覆盖不足。** `visual_qa.py:276`仅预览PDF第一页，布局检查只覆盖部分字形/越界/相邻刻度，未覆盖全部图例压数据、跨面板对齐或科学语义。CLI可只打印提示而退出0。上游假定某宿主Read工具具备多模态能力，不能移植为枢模所有供应商都已读图。最终页图/每幅正式图应按实际能力检查，作者修改后须重渲并重新审查受影响内容。

**HTML面板不能承担权威审批或正式导出。** 它用占位图名和相对SVG对象，勾选状态仅在浏览器内。`exportPNG`把像素乘3并注释“300 DPI output”，但没有绑定最终物理尺寸或生成可校验的300dpi交付证据；不是合格分辨率的证明。建议仅作为可选浏览/讨论界面，接枢模图目录、哈希和权威用户决定，正式原件仍由受控绘图链输出。SVG对象、HTML插值及浏览器导出尚未做安全/兼容性测试。

**期刊、样式和接口仍需核验。** 期刊规格表是来源声称，本轮没有在线核验其现行宽度/字号/字体/投稿工具。2026观察没有逐篇样本或方法索引，不当作当前权威结论，也不强制hero panel或45–60%比例。入口137行的MATLAB示例把png/svg传入第三参数，而此前已审函数第三参数是double dpi，静态参数类型不匹配，未做MATLAB运行验证。另有18条按当前Markdown相对路径无法找到的链接，旧扁平路径应在适配时重整。

**来源与署名不能靠改名解决。** 资料明示继承nature-figure、scipilot-figure-skill和figures4papers等来源，需逐级核验相应许可；产品/论文不暴露私有本地路径，不等于隐藏合法必要的版权署名或拒绝项目审计。固定快照中的docx/pdf/xlsx许可证不能覆盖本类原文。
