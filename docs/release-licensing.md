## 可审阅的处理建议

建议项目原创部分采用 Apache-2.0，保留官方 Apache 文档工具原许可与署名；对 PyMuPDF 优先评估替换为许可更适合目标发行方式的 PDF 读取/渲染组合，保持全页检查能力。现有 pypdfium2 也需完成其 PDFium 及组件许可核验后才可选用，不能直接宣布替换后已无许可问题。

这是待项目所有者选择的建议。本轮没有写入主 LICENSE，没有改变 PyMuPDF 功能/依赖，没有宣称 Apache-2.0 可以覆盖 AGPL 组合义务，也没有购买商业许可。先前 238 项功能回归属于 F4，不冒充 F5 许可审查或替换回归。

后续按确定的发布方式处理主 LICENSE 和 metadata，补全 THIRD_PARTY_NOTICES 与包内声明、固定来源及许可证文本，再构建新候选核验 wheel/sdist 的许可完整性。旧 F4 产物不覆盖。所有许可范围清除和功能回归完成后才可收口 F5，公开上传另需明确授权。
