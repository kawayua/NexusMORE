# 枢模 Python 数据、绘图导出与 PDF 检查

2026-11-12 用户决定：后端、数值求解、数据处理、绘图与导出统一 Python。当前规范不采用其他语言路线，不使用上游 HTML 面板。HTML 原件是候选图浏览、缩放和勾选网页，其浏览器状态不是枢模批准；本项目沿用版本绑定的图目录、PNG/PDF 预览和明确用户选图记录。

新三手运行冻结 collaboration guidance 1.1.0。代码手、论文手、P2/W1/W2 读取相同的 Python 与全页 PDF 要求。旧运行按自身冻结上下文恢复，原始来源、历史批准及旧政策字节不改写；历史科学绘图文档中其他语言的设想不代表当前支持范围。本轮未复制、导入或执行未授权的上游配图脚本。

## 完整数据

`modelcrew.figure_data.read_data(source, header=..., sheet=..., expected_rows=...)` 读取 CSV/TSV/XLSX。表头必须明确指定，XLSX 必须指定工作表；不猜测首行为表头，不静默删空行、缺失值或截取前几行。保留完整原记录、行列数、输入哈希和空变换清单，行数与资源限额不符即失败。XLSX 读取实际 XML 末尾，避免错误的工作表尺寸元数据导致少读行列。

`profile_numeric(data, columns, units=...)` 要求每列明确单位，按列报告有效/缺失数，按每对变量报告有效样本数、缺失行数和 Pearson 相关系数。无足够样本或常量数据时系数为空并注明原因，不编造相关性；原始数据不变。布尔值、非有限值、未计算的公式表达式均不能冒充数值。此处不接通表格公式重算；抽样、排除、插值、聚合仍须按具体任务留痕并核验。

## 图形导出

`modelcrew.figure_tools.export_figure(figure, output_dir, figure_id=..., binding=..., inputs=..., code=..., parameters=...)` 接收已创建的 matplotlib Figure，在新目录输出 PNG/PDF/SVG、独立灰度图、PDF 逐页预览与检查报告，绑定数据/代码哈希、任务、合同、执行和结果版本。PNG 至少 300dpi，并核对最终物理尺寸；不使用 tight 裁剪悄悄改变尺寸，不覆盖原 PNG 生成灰度图，导出后恢复 matplotlib 全局设置。抑制 PDF/SVG 动态日期及 SVG 随机标识，重复导出校验字节一致。

导出先写 `.incomplete`，全部检查通过再移出文件，最后写 `figure-export.json` 成功标记。失败保留失败记录，无成功标记不得准入；不能用覆盖开关重写旧输出。缺字、过小文字、页外文字、Type3 字体、实际尺寸/分辨率不符、输入或代码改变均阻断。

这是 Python 辅助 API，不在宿主执行生成脚本；生成代码仍经原受控执行器。未宣称所有 Docker 镜像已安装本模块及依赖，或每个 harness 已注册成可调用工具。依赖见 `pyproject.toml` 的 `figures` 组和 `configs/dependencies/figures.txt`；安装和镜像验收属于相应后续任务。

## 全部 PDF、全部物理页

`modelcrew.pdf_checks.inspect_pdf(source, new_output_dir)` 用 PyMuPDF 全页渲染，用 pypdf 核对真实页数并递归列出 Form XObject 内字体和 Type0 子字体的嵌入情况。逐页记录预览哈希、尺寸、实际文字字号、页外文字、缺字和字体检查结果。超出页数/像素限额明确失败，不抽样或截断；缺依赖报错，不按“跳过”通过。字体未嵌入、无可提取文字等警告保留待实际审阅，机械通过不能清除这些警告。

检查整个指定交付目录可运行：

```powershell
python -m modelcrew.pdf_checks <PDF文件或交付目录> <新的检查目录>
```

目录模式递归检查全部 PDF，继续收集各文件失败，并以非零退出码报告 FAIL/BLOCKED；检查目录必须在被扫描目录之外。每份文档及每页均留报告与预览。它不是对仓库所有历史、缓存或未授权资料自动重签的命令。

新规范代码手在 P2 前用 `audit_catalog` 检查所有候选图、三格式与全部 PDF 页，报告/预览归档并封存；恢复核对全部预览与源文件哈希。新论文手入口在接收已批准结果图目录后重新完整检查。当前正式导出脚本在编排前检查全部候选图，LaTeX 编译后完整检查论文 PDF。正式论文渲染器对 LaTeX 与 Word 原生渲染 PDF 均全页检查；新报告进入 W2 时核对实际 PDF 页数、逐页预览及实际派发页图列表，缺页或改变即阻断。旧报告仍按旧协议保留，不冒充已包含新检查。当前独立多模态请求保留最多100张页图的既有上限；两种格式合计超限时必须阻断并安排后续分批审查实现，不能截取前100页或宣称完整W2通过。

自动结果只标记机械检查状态，`visual_review=PENDING`、`independent_review=NOT_RUN`。逐页实际读图、最终缩放可读性、统计意义、单位、遮挡、配色与跨面板对齐仍按现有流程审阅；未实现通用碰撞/对齐算法或新 P2 多模态审图接口，不宣称自动覆盖。独立 M1/P1/P2/W1/W2、用户模型/结果确认、正文和选图双确认均保留。候选图格式导出不能替代正式论文导出许可，通用文档转换、公式重算、跨任务通用正式导出仍按后续任务接通。
