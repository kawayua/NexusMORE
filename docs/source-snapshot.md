# 源码快照范围

本仓库首个快照保存 枢模 · NexusMORE（原名 ModelCrew）源码、工作流契约、迁移脚本、测试、配置示例、项目自编算法索引与论文规则，以及选入的阶段总结。当前工程状态见 [E 阶段收口报告](../archive/research/stages/stage-e/implementation/20261110-upstream-continuation-v1/E阶段联合验收收口报告.md)，后续安装、宿主接入与发布工作见 [F–H 路线](open-source-harness-roadmap.md)。

运行时数据库、密钥、任务原始附件、过程证据及论文成品保留在原工作区。历史文档中的部分路径指向这些本地材料。仓库未纳入未确认可再分发的外部算法原文、引用摘录和论文模板；算法索引仍会标出相关资料，论文上下文入口也仍校验 [workflow.json](../src/modelcrew/resources/paper/workflow.json) 列出的文件。使用对应流程前，需自行合法获取所需资料，通过当前资源定位与合法本地来源配置提供；本机历史副本已移至 `archive/research/knowledge/`，不会随wheel/sdist发行。开发工作区旧逻辑路径由精确迁移映射解析，源码外新安装不自动拥有这些资料。包含赛题全文的两个历史输入契约样例也保留在本地。部分验收脚本和测试还需本地数据或服务，无法仅凭这个快照复现全部历史结果。

这是项目当前成果的 Git 快照，尚未附开源许可证；安装、第三方资源整理和完整 harness 接入仍以 F–H 的实际交付为准。


2026-11-11目录收口：必要Schema、SQL、监督器、项目规则和官方文档工具进入包资源允许清单；阶段原件与旧UUID工作副本分开保留。wheel/sdist已离线构建并进行源码树外安装/资源核验，使用现有依赖，不等于干净环境完整工作流验收。当前文档中通往本机档案的导航仅供拥有该档案的工作区使用；受冻结上下文约束的两个原链接文字保留，可通过历史导航/映射定位，不为整理目录改写原上下文哈希。
