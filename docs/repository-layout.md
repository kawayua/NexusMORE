## 面向使用者和贡献者的目录

公开仓库按功能组织，不在根目录继续新增 `stage-a`、`stage-b-plus` 等研究阶段目录。A—H保留为项目内部里程碑编号，可出现在路线与历史记录中；产品源码、命令和默认输出路径不以阶段编号命名。

目标布局如下；最终目录清单在F0盘点后冻结，不为凑齐结构创建空目录。

```text
NexusMORE/
├── README.md
├── AGENTS.md
├── pyproject.toml
├── LICENSE
├── THIRD_PARTY_NOTICES.md
├── src/
│   └── modelcrew/          # 保留现有Python包名，避免混入包改名
│       ├── ...            # 按建模、执行、写作、审查、编排职责组织源码
│       └── resources/     # 随包安装的知识、模板、Schema、迁移及第三方工具
├── configs/               # 服务部署与配置示例，不含真实密钥
├── docs/                  # 安装、架构、工具、规范和路线
│   └── history/           # 经审查可公开的阶段总结与历史导航
├── examples/              # 可公开、可复现、许可明确的业务示例
├── scripts/               # 按用途命名的维护、迁移与检查入口
└── tests/                 # 按功能组织的测试和合成fixture
```

本地运行数据、数据库、输入附件、历史通过稿与证据保留在独立可配置的数据目录；研究原件可保留于本地 `archive/research/`，默认不进入发行包。归档不等于全部上传，具体公开范围受许可、隐私与快照清单约束。安装包只包含运行所需内容，不将历史验收包、缓存和论文成品当作默认资源。

## 命名规则

项目自编目录及普通文档默认使用表达用途的英文小写短横线名称，如 `paper-export`、`tool-integration.md`；Python模块、函数和测试文件遵守 `snake_case`，如 `document_tools.py`、`test_document_tools.py`。避免空格、`+`、大小写混用和只用阶段字母表达功能，兼顾Windows大小写不敏感文件系统。

配置使用实际用途名称和明确扩展名。项目自编Schema、接口等版本化契约保留显式版本号。用户交付物可使用清楚的中文名，如 `论文审阅稿-v001.md`，版本目录承载迭代，禁止反复覆盖或使用“最终版2”“最新最终版”等名称。用户题目编号、任务ID、版本ID和阶段编号分别保留其含义，不为目录美观重新编号。

`README.md`、`AGENTS.md`、`SKILL.md`、`LICENSE.txt` 等规范入口和第三方原始文件名保持原样，不强行套用项目小写规则。上游工具整体移动时只更新项目路径映射，不重命名其中的源码、Schema、许可证及指南。与历史内容哈希绑定的文件不批量替换名称或正文。

## F0执行与验收

先盘点所有文件的角色、调用方、许可、是否必须随包安装，以及数据库、清单、文档、脚本中的路径引用，形成逐项旧路径→新路径映射。特别查明运行时对 `stage-*` 的真实依赖，不能仅把目录改成一个漂亮名称。

迁移分批进行：先建立新布局和路径定位接口，再迁移源码、配置及可发行资源，最后迁移可公开历史导航。F1/F5的资源和许可决定应先用于相应批次。同步更新导入路径、CLI、配置、Docker挂载、资源定位、工具下载位置、文档链接、测试路径、`.gitignore`、`.gitattributes` 和打包清单。

历史冻结材料、数据库引用和批准绑定不得使用全局搜索替换。迁移映射保存旧路径、目标、原始哈希、用途和执行记录；通过明确限定的兼容解析或新版本迁移记录恢复旧引用，拒绝越界或冲突路径。若内容发生变化，生成新版本并按影响范围重新确认，不能为使检查通过而改旧哈希或伪造批准。迁移前保留可恢复备份，记录中断恢复及回滚办法。

验收必须覆盖：

- 新公开仓库根目录无 `stage-*` 目录及散落的研究产物，历史导航可访问；仅隐藏README中的链接不算整理完成。

- 必要功能测试、资源哈希、文档链接、配置/容器路径检查通过；相关检查脚本和说明按功能命名。
- 任务暂停恢复、跨题引用、历史批准及旧冻结材料仍可核验，不丢记录、不重复执行。
- 在源码树之外安装wheel/sdist后可定位资源；Word/PDF/表格三个SKILL入口与配套工具完整，且上游字节哈希不变。
- 设置根目录允许清单与命名检查，防止新增阶段目录和临时产物再次进入公开仓库；对规范入口、第三方文件和历史原件设置有依据的例外。
