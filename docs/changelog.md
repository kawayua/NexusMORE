# 更新记录

当前开发版本：0.1.0.dev0。此页描述公开产品变化，未发布正式二进制版本。

## 开发预览

- 提供建模、代码、论文三手协作及M1/P1/P2/W1/W2独立检查入口。
- 接入DSH原生会话、文件审阅、可信用户确认与中断对账。
- 支持当前版本正文与配图合并审阅，并保存各自的确认范围。
- 内置算法、数学论证、中文论文资料和受控文档工具入口。
- 提供Python受控计算、配图、同源文档导出和全页PDF检查。
- 整理面向使用者的配置、安装、排错、架构和贡献文档。
- 公开视图保留产品代码、必要资源和合成测试，过程档案单独维护。

兼容范围和仍未支持的事项见[兼容说明](compatibility.md)，用户流程见[使用指南](user-guide.md)。
