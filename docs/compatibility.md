## 模型服务按实际配置验证

后端使用已配置的 Chat Completions 路径，客户端会发送结构化输出参数及 `enable_thinking` / `thinking` 扩展字段。端点接受普通文本请求不表示它接受全部阶段参数；图片、JSON/schema模式、上下文/输出上限均需按提供方和具体模型验证。当前不能用统一兼容名称宣称所有服务可互换，也没有模型失败后静默切换的承诺。接口范围见[原说明](model-interface-scope.md)，请求实现见[模型客户端](../src/modelcrew/model_client.py)。

模型端点、模型名和密钥由使用者选择，图片质检须使用实际支持图片的审查模型。缺少图片或响应证据非法时应阻断，不能把文本自述当成已读图。运行、独立检查和真实用户确认分别记录，不保证无人干预的科学正确性。

## 当前证据怎样解读

G5 的417项记录属于当次测试和内容身份，不是本轮重跑、新题求解率或跨环境通过率。其问题一记录不代表整套研究赛题完成，已经暴露的历史题不属于新留出题。既有已接受数值偏差保留原阈值FAIL及限定范围，不能因G通过就改成原精度达标。

本机源码外安装、独立Python/工作区和资源校验各有历史证据，但仍与一台全新设备不同。H1/H3本轮未继续推进，因此没有新留出集性能或有/无契约对照优势可对外报告。

## 发行与信任边界

当前为 `0.1.0.dev0` 私有开发候选，许可/对应源码、第三方材料、敏感信息与发行包完整性按H5及既有F5事项核对。将新设备测试延期不免除这些事项；本轮没有上传仓库或包，也不把文档完成写成公开发行完成。

本地单用户可信边界沿用同一OS账号与已核验宿主父进程/管道身份，不是面向公网的多租户认证，也不能防御同账号任意代码执行。配置/审批语义见[架构说明](architecture.md)和[可信决定](trusted-user-decisions.md)。源码中存在旧维护入口或兼容实现不等于推荐用户绕过当前业务流程。
