# 支持范围与限制

当前为0.1.0.dev0开发预览。已有本地Windows/DSH业务实测，新设备完整安装由维护者后续验证。源码可阅读、构建和贡献，安装前核对自己的运行条件。

| 项目 | 当前范围 |
|---|---|
| 主机 | Windows x86_64、CPython 3.13；已记录本机Python 3.13.5，不推断所有补丁均验证 |
| 宿主 | DSH Desktop 0.2.2-rc.1；其他宿主与新版本尚待各自联调 |
| 执行 | Docker Desktop/WSL2 Linux amd64容器、Python 3.13；容器补丁与镜像身份单独记录 |
| 后端 | Python，不声称支持MATLAB或R |
| 算法资料 | 包内七类索引及几何补充，名称/ID/类别字面查询；不是全部算法的语义向量索引 |
| 论文检索 | 另配嵌入模型、Qdrant和论文索引；候选不等于文献真实性核验 |
| LaTeX | Tectonic 0.17.0、Pandoc 3.6.4；批准Markdown/AST同源导出 |
| Word | 原生OMML公式；实际原生渲染需已授权Microsoft Word与字体 |
| 暂不支持 | 其他LaTeX引擎、外置BibTeX/Biber、任意TeX→Word、公式重算、修订接受/合并或任意公式编辑 |

Linux执行容器不代表Linux/macOS主机兼容；Windows ARM64、Windows容器和其他Python次版本未获当前支持验收。单次示例或本地业务通过也不能解释为新题总体求解率。

## 模型接口

客户端使用已配置的Chat Completions路径，按阶段返回JSON或Markdown，发送相应结构化和`enable_thinking`/`thinking`扩展参数。端点接受普通聊天不保证兼容所有阶段参数；图像、JSON/schema模式、上下文与输出上限要按具体服务和模型核对。

图片审查必须有实际图像证据和支持的审查模型。缺能力明确报告，不静默切服务或把文字自述当成读图。模型请求成功不保证数学/物理正确，显示小数位数不证明误差达标。
