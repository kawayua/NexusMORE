索引版本：1.1.1；更新：2026-11-06。此文件是项目内置导航。七类算法完整说明及原索引已复制到 `reference/`，不再依赖外部 Skill 路径读取。复制原文保持字节不变，来源、版本和 SHA-256 见[导入清单](provenance.json)；项目新增观点见[选型与验证补充](modelcrew-notes.md)。这些资料尚未全部验证或接入自动检索/路由。源目录未发现适用于这些文档的根目录/assets 许可声明，来源信息予以保留，复制不据此推定公开再分发许可。

## 加载顺序

每个小题先完整理解题目与数据，读取本索引，再根据问题类型及结构加载一个或少数几个相关资料的适用条件与章节。先核对假设、输入、约束、规模、依赖和验证方式，再确定候选方法；必要时补充原始论文/官方 API。不要一次加载七份全文，也不要跳过前提只取代码。

读取顺序：本索引 → 相关类别/小节 → 条件核对与方法比较 → math-reasoning 数学形式化/推导/审查 → 版本化方案与用户确认 → 受控求解与结果确认 → 论文。检索只是定位资料，不能替代实际读取相关公式及前提。未读资料和未运行代码不能标成已核验。

## 一次加载需要留下的记录

保存 index_version、题目结构标签、选中的类别/资料路径与章节、内容哈希、实际读取范围、适用条件的满足/不满足/未知项、候选方法及取舍、未覆盖缺口、来源核验状态。后续导入项目资源时使用项目相对路径、保留来源与许可说明，并记录版本和哈希；不把用户绝对路径写成必须存在的部署配置。

只有被采用的相关章节、数学依据和必要 API 进入当前角色上下文；完整语料保留在资料层。无合适方法或证据不足时回到问题分析或补充检索，不强制命中索引中的算法。
