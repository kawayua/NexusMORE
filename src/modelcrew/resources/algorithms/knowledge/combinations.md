# 枢模算法组合与交接边界

版本1.0.0；2026-11-14；独立编写。先读索引与各组件条目，以下为用户主题清单的20种跨领域组合适配说明，不是20个已训练或自动接通的求解器。每条交接均须保存输入/输出、单位、数据划分、参数、版本与哈希，沿用三手协作和独立节点；组合失败应报告组件状态，不能以总流程“成功”掩盖局部失败。

| 组合及组件ID | 交接与验收重点 | 失败边界 |
|---|---|---|
| 熵权→TOPSIS（entropy-weight,topsis） | 固定方向与非负标准化矩阵，传递归一权重，逐对象重算理想点距离 | 零列/常量列及秩逆转；熵权非重要性证明 |
| AHP＋熵权→TOPSIS（ahp,entropy-weight,topsis） | 两套权重各自合格，再明确融合系数和归一方式，检查扰动排名 | 不能任意平均不同尺度权重，融合不消除主观偏好 |
| PCA→K-Means→TOPSIS（pca,kmeans,topsis） | 训练内拟合载荷，保留特征解释与簇稳定性；评价用有意义指标及方向 | PC正负可翻转，不直接当收益指标；聚类标签不能直接变分数 |
| ARIMA＋XGBoost（arima,xgboost） | 滚动折内拟合线性部分与折外残差，确定组合方式和最终未见测试 | 全样本残差再随机分折会泄漏；不保证混合优于基线 |
| GM(1,1)＋Markov（gm11,markov） | 训练残差状态阈值、转移矩阵与修正回算写明，检验样本充足性 | 小样本转移估计稀疏，不能以一次修正证明稳定提升 |
| PSO＋BP网络（pso,mlp） | 固定网络/损失及参数编码、搜索预算，训练验证分离并比较梯度基线 | MLP前向案例不是完整反向传播/PSO训练；搜索不保证全局最优 |
| GA＋SA（ga,sa） | 明确局部搜索嵌入时机、温度、可行性修复与总目标调用次数 | 不可用更多评估预算造成的优势冒充算法优势 |
| NSGA-II→TOPSIS（nsga2,topsis） | 先取可行非支配候选，再按确认偏好排序，保留前沿与排序敏感性 | TOPSIS只排序候选集，不证明前沿完整或给出唯一业务偏好 |
| 图建模＋整数规划（ip,milp） | 节点/边到变量映射、流守恒/容量/整性、路线连通及子环约束 | 只给整数变量未消除子环会产生不合法路线 |
| Dijkstra＋ACO（dijkstra,aco） | 非负图上预计算成本，ACO负责组合序列，最终还原逐边路径核验 | 预计算距离不代实际路径/容量/时窗检查 |
| DEA＋Malmquist（dea,malmquist） | 单元、年份、导向、规模报酬和距离函数同约定，保存跨期线性规划状态 | 不同单位或不可行交叉期距离不能直接相除 |
| Monte Carlo＋Sobol（monte-carlo,sobol） | 独立输入设计、A/B及混合样本矩阵，重复估计和误差区间 | 随意复用同一列或相关输入会破坏经典分解 |
| ODE＋Monte Carlo（ode,monte-carlo） | 参数采样层与积分误差层分开，逐样本记录求解状态与事件 | 数值失败样本不能静默删掉后计算风险 |
| Random Forest＋SHAP（random-forest） | 解释背景分布、输出概率/对数几率及相关特征处理另行定义 | SHAP非因果；SHAP尚非本版113条中的独立案例或接通后端 |
| LightGBM＋Optuna（lightgbm） | 嵌套/时间验证，搜索空间、预算、种子与停止规则留痕 | Optuna仅为待适配搜索工具，不登记已安装/已验收 |
| 聚类＋判别分析（kmeans,dbscan等） | 分清无标签探索与有监督目标，独立真实标签评估；判别模型另行建契约 | 用聚类标签训练再声称外部分类准确率属于循环验证；LDA/QDA未列独立案例 |
| 排队论＋离散事件（queueing,discrete-event） | 同到达/服务假设下核对均值，仿真预热、重复和区间单独记录 | 稳态不满足时不能套M/M/1均值；有限时域结果不必等于稳态 |
| 系统动力学＋多目标（system-dynamics,multi-objective） | 每候选参数运行守恒/稳定性检查，再比较可行多目标结果 | 优化器会利用数值伪影，必须缩步复验候选 |
| 回归＋Bootstrap（linear-regression,bootstrap） | 每次按正确单位重采样并重跑必要预处理，明确区间方法 | 时间/簇数据逐行独立抽样会低估不确定性 |
| 贝叶斯网络＋Monte Carlo（bayesian-network,monte-carlo） | DAG/条件概率表先归一，再抽样推断并对小网精确枚举比较 | 稀有证据下拒绝采样效率低；未观察混杂不因概率推理消失 |

七章其他组合应按相同组件接口展开：PCA→SVM需训练内转换；ADF→ARIMA须用正确临界分布和时间验证；DID＋PSM仍需平行趋势/重叠与聚类推断；最大流与最小割须核对同一容量网络；LSTM＋Attention需逐维核对状态与因果mask；元胞＋ABM需固定同步顺序与边界。未单列的贝叶斯优化、SHAP、Optuna、判别分析等扩展主题不计入已验证113例，不能把组合建议升级为支持范围。

## 组合算术自检例

熵权→TOPSIS可先用非负矩阵Z=[[1,0],[0,1]]：两列熵皆0，权重各0.5；采用向量标准化时，两对象到正负理想点距离均0.5，贴近度各0.5，必须报告并列。这仅验证交接算术，不能据此认定真实指标合理。完整案例仍按各规范ID执行；组合后必须另做任务数据验证与审批。
