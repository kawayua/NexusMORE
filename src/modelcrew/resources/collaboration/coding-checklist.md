# 代码交付与复现自检

核对已确认合同/数学绑定、原输入哈希、数据行列/首末记录、种子/参数/依赖、真实执行状态、退出码、关键数值和单位、边界/约束、结果文件与输出哈希。最小、全量、复跑的证据和声明范围分开。

结果与图均来自当前真实执行，目录绑定 execution_id/revision。PNG/PDF/SVG 是同一逻辑图的不同格式，灰度预览和面板不重复计数。机械检查报告失败必须阻断，不能因 CLI 恰好返回 0、缺少 strict 参数或只看到文件存在就准入。

复现记录含输入、代码、参数、环境、实际命令和输出身份；超时/断连记录未知状态并查询，基础设施失败不消耗代码返工预算。作者自检清单是证据，不代替独立 P1/P2 或用户结果确认。
