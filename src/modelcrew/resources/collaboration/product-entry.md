# 枢模共享能力入口

产品为枢模 · NexusMORE，Python包和命令保留modelcrew。共享入口 python -m modelcrew.capabilities，读取包内版本化注册表、实际模块及资源身份；宿主共用同一入口，不复制另一份知识库或导入上游dsh预设。运行目录按用途/任务版本命名，不强制复制外部使用指南。必要版权、许可和署名保留，不因独立实现能力目标而改变原件许可。

程序编排器管理三手、版本与恢复。建模手包含Planner/Researcher/Modeler，代码手Coder，论文手Writer；不新增总指挥Agent。M1/P1/P2/W1/W2仅用未参与被审产物的独立只读上下文。资源检查、作者自检、独立审查和用户确认分开记录。不得因本次规范更新重写旧冻结任务、历史产物或批准。

后端统一Python。模型数量由题目与证据决定，不照搬最多两个模型等限制。先确认模型与结果，中文Markdown正文和最终选图分别确认后才同源正式输出。唯一全局符号表位于假设后、模型前。所有PDF均完整页数、全页预览和检查，机械通过不代审图或W2；真实数值、单位、文献和当前官方规则需实际核验。

当前支持Tectonic 0.17.0/Pandoc 3.6.4/Python 3.13，Windows缓存编译与本机Word渲染已实测。其他编译引擎、外置BibTeX/Biber、自由LaTeX→Word暂不支持，不作为本批必补项。已有原生OMML路线以批准Markdown/AST同源生成；任意占位符公式编辑、公式重算和全部宿主自动路由不能凭入口存在宣称接通。新来源、格式或依赖需明确范围和实际验收，不自动安装外部技能或宣称完整知识发行已完成。
