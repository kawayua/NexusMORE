# 版本化模型与数学契约

契约从实际题目和已核验附件形成，分别说明任务范围、输入字段与单位、边界/数据质量、结论类型、变量/参数/目标/约束、算法停止条件、依赖、输出、验证和失效条件。使用已有 contracts/model-contract-* 与数学包 schema，不另造一个不受校验的“报告合同”。

交接至少核对 task_id、contract_version 和 contract_sha256，数学包绑定同一契约，来源及输入保留原哈希。跨题只引用已确认且依赖满足的结果，并记录原任务、版本、执行与 revision，依赖变化时阻断旧引用。

修订使用工作流 revise_model/revise_mathematics 等已有入口，生成新版本/呈现记录；不原地覆盖已通过合同、论文或数据。不删除/弱化已有 checks，不以超时自动抽样、换模型或降低精度；有变化先说明影响，再走新方案审查与用户确认。检查计划中的 unknown 不冒充已经执行，也不因尚未求解就编造数值。
