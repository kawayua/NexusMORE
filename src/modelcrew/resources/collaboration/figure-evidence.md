# 候选图、正式图与证据

默认三类 raw/process/result 各至少3张，合计至少9张逻辑候选图；正式入文至少8幅，各题类别覆盖按当前 chinese-modeling-policy 执行。PNG/PDF/SVG 保留同图版本，PNG至少300dpi，灰度预览不另计图数。正式图有连续编号、中文题注、正文引用和真实来源。

每图先说明科学问题/核心论断、真实数据版本、统计口径、单位、最终物理尺寸和证据作用；多面板围绕共同论断，不拼无关图。误差条和置信区间须有真实重复/统计依据，示意图明确标注，不作为数值或碰撞检验。

运动或几何题按题目/用户要求绘代表时刻位置和局部细节，轮廓/尺寸来自已核验输入，不对无关题型强加时间图。按科学绘图规范检查可读性、缺字、裁切、尺度、图意及灰度；自动元数据检查不替代实际读图和最终论文尺寸检查。

用户修改图数或官方规则覆盖时保存有来源的新政策版本，不能临时减阈值。增补未入文候选图保留字节未变的正文批准；入文替换或选择变化重新确认受影响部分。


## Python 与全页 PDF 检查（2026-11-12 用户决定）

本项目后端、数值、数据处理、绘图与导出统一 Python。历史参考里的其他语言路线不属于本项目当前支持范围。数据入口必须显式声明表头、工作表和单位，保留原数据与变换记录；输入未验证、公式未重算或统计口径不明时不能生成确定性结论。

所有候选图（含未选入正文的图）的 PDF 全页渲染、全页检查；正式论文 LaTeX PDF 与 Word 原生渲染 PDF 也逐页检查。检查页数须与实际 PDF 一致，逐页保存预览及哈希。通过机械检查后仍须实际查看每一页、每个面板，并记录警告处理、图意与最终尺寸可读性；不能把已生成预览写成已审图或独立通过。自动检查失败/依赖缺失分别报告 FAIL/BLOCKED，不跳过、不降级为提示。

不采用上游 HTML 面板。候选图和 PNG/PDF 预览沿用枢模现有图目录和明确用户选图记录；网页勾选不作为批准，不经浏览器重导出正式图。
