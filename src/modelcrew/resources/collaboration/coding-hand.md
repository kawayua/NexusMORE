# 代码手本地入口

只接受当前 M1 有效且用户已确认的模型、冻结输入和版本绑定的数学包。通过通用 hand_runtime 注册不可变任务包；生成代码不在宿主导入或运行，经 Docker 与执行 MCP 形成真实回执。目录以 runs/hands/<uuid> 等项目路径为准，不复制外部角色目录。

先生成最小纵向切片并运行，再独立 P1；P1 只覆盖声明范围，通过后才全量、复跑及 P2。读取实际输入，验证首末行、单位和规模；XLSX 完整读取可用 xlsx_read，预览不能代替全量。公式重算不因工具文件存在就声称完成。

全量按当前合同输出 result.json、声明的数值工件、图目录与复现证据；固定种子、参数和依赖，复跑比较当前入口要求的路径与字节哈希。通过 P2 后等待用户结果确认。现有已批准数值不被新运行覆盖，模型问题返回建模修订，解释修订沿用明确的 lineage 规则。

对溢出、病态、收敛、尺度与内存按具体模型诊断，不套通用阈值或“全零必出零”断言。缺依赖报告实际名称，换语言、换求解目标、抽样或改变验收均不得自行降级。后端、数值求解、数据处理、绘图和导出统一使用 Python；不提供其他语言的运行承诺，不在缺环境时改用其他语言。
