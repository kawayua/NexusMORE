# 受控文档工作区

按类型实际读取包内document-tools/upstream的docx/pdf/xlsx入口及必要参考，核验固定Apache官方126文件。原指南中的其他语言/自动安装设想不覆盖Python后端及枢模契约。只调用已注册实现，不执行本机受限文档扩展。

modelcrew.office_tools提供诊断、DOCX只读模板画像、受控Office解包和重打包工程检查。输入只读，新输出目录写一次；限制ZIP成员、总展开大小、链接路径与外部关系，保存源文件/各成员哈希，XML不自动美化，run与修订不自动合并，不默认修复或猜作者。重打包限定未修改的原成员集合与字节，用于无损工作区往返；修改后的正式文档必须走明确的编辑任务、结构校验、真实渲染与审批，不能借pack发布修改稿。修订整理/接受、任意公式占位符替换仍未注册。

模板画像读取分节、默认格式、样式及basedOn继承、主题和直接格式，保留未解析项；不按字号或样例标题猜官方角色，不声称已算出完整Word布局。无法解析/循环继承/损坏输入明确失败。画像不产生论文，也不代替官方规则来源或全页PDF检查。环境诊断记录实际依赖版本，原生Word渲染需另行实际运行，模块存在不代表完整导出可用。

完整表格读取复用document_tools.read_spreadsheet/figure_data：保留首末记录、空值及公式文本，读取实际工作表XML，显式表头和预期行数/大小检查。读取缓存与公式重算分开，当前公式重算不注册。Word原生数学公式复用批准Markdown/AST经Pandoc的同源导出和OMML/实际渲染检查，不采用会抹去数学字体语义的简化解析器。其他LaTeX引擎、外置BibTeX/Biber和任意TeX转Word暂不支持。

工作区工具回执是工程检查，不是论文语义正确、逐页审图、独立W2或用户批准。正式论文继续遵守中文Markdown先审、正文/选图分别确认、同源导出和全部PDF页检查。未经核验的15000字/20页/30页等阈值不加入项目默认；警告不得静默过滤，页数必须来自实际PDF。
