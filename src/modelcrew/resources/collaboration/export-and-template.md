# 同源导出与模板边界

本文件是自行编写的模板要求，不携带或批准上游 DOCX。正式输出前正文及选图分别明确通过，绑定模型/结果/正文/图目录/政策版本；模板来源、适用任务、哈希和许可另行记录。官方模板只在核验适用届次后采用，当前项目研究模板不是官方认证模板。

Word 使用原生公式并验证结构/文本/图表/引用和实际版面；LaTeX 真实编译并核对引用、字体、页数、插图和产物绑定。各格式共用一份正文、数值、符号与图清单，不分别生成矛盾论文。标题摘要关键词首页、正文第二页和全局符号规则对所有格式一致。

正式导出保存原文与构建日志、渲染证据和独立 W2；公式转换、公式重算、追踪修订及通用正式导出需实际工具注册/引擎/渲染验证，不因上游命令存在就视为可用。不覆盖已批准版本，不以工具链探针冒充正式论文。

Python 为统一后端。所有正式 PDF（含 Word 原生渲染的 PDF）均须完整页数核对、逐页预览与机械检查，W2 必须收到全部实际页图；不得只看首页或抽样页。缺失页、预览哈希改变和检查失败阻断准入。候选图导出不等于正式论文导出许可，仍遵守正文与选图双确认。
