# 模型适配与验证计划

从问题结构、可用数据和验证证据选择方法：优化关注可行域和变量类型；预测关注时间顺序、外生信息与泄漏；评价关注指标方向、相关性及权重依据；图模型关注节点/边/方向/连通性；仿真关注机制、分布和校准；学习任务关注标签与代表性。候选类别是导航线索，不能按题号或样本少就机械套某个算法。

模型数量由已确认任务和证据决定。主模型、对照、串联阶段应解释各自必要性；验证、误差和灵敏度方法不因名字不同就凑模型数量，同机理近似应说明关系。不把外部“最多两个模型”或假设数量直接写成枢模通用硬约束，也不把简单方法改名当创新。

优先预先规定失败条件、量纲/边界、数值误差、可行性、回测/留出集、稳定性或适当对照。阈值应有题目、原文、数据或数值分析依据。近优解不冒称全局最优，对照吻合不等于严格证明，确定性问题不强加统计区间。
